STEP 3: EXACT COMMANDS TO RUN
================================================================================

Copy and paste these commands ONE BY ONE:

# Initialize Git repository
git init

# Check what's being staged
git status

# Stage all files (ignores large files via .gitignore)
git add .

# Verify staged files (should NOT include plantdoc_reorganized/ or outputs/*.pt)
git status

# Create first commit
git commit -m "Initial AgriSight project upload"

# Rename branch to main
git branch -M main

# Add your GitHub remote (REPLACE <YOUR-REPO-URL> with your actual URL)
git remote add origin <YOUR-REPO-URL>

# Verify remote is set correctly
git remote -v

# Push to GitHub
git push -u origin main

================================================================================
TROUBLESHOOTING
================================================================================

"fatal: not a git repository"
→ Run: git init

"remote origin already exists"
→ Run: git remote remove origin
→ Then: git remote add origin <YOUR-URL>

Upload is slow/stuck
→ Check if large files are staged: git status
→ They should be ignored by .gitignore

Can't push
→ Check remote: git remote -v
→ Verify GitHub URL is correct
